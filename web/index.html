Site scanner

Tests WiFi, The Things Network and Helium at one spot, and keeps a report for each spot. Use Chrome on Android, or Bluefy on iPhone. When asked, type the 6-digit code the board shows.

Spot

Fill in where the board is, then save. "New spot" starts a fresh report; "Save" changes the current one.

Run tests

A full run takes a few minutes. The board's screen shows the same progress, and a short press of PRG runs all tests without a phone.
